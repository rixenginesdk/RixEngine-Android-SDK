Stable Release

RixEngine Android SDK v4.4.0

This release brings a full new iteration: greater stability, faster performance, and more advanced capabilities and platform support.
01More Stable Stability
  • Proven in production: Built on a stable release validated over the long term across multiple apps and games — safe and reliable.
  • Legacy bugs fixed: Multiple internal iterations resolve known production crashes and ad display anomalies, clearing long-standing bugs and improving stability.
  • Broad device compatibility: Adapted to the latest Android versions and a wide range of devices, including phones, tablets, and foldables.
02Faster Speed
  • Cold / warm start caching: Built-in dual caching for cold and warm starts — faster preloading on warm start, quicker ad loading on cold start.
  • Weak-network optimization: The request pipeline is specifically optimized for weak-network environments, significantly improving request success rates in those regions.
  • Low-end device optimization: Loading and rendering optimizations on older devices avoid out-of-memory issues and add safety safeguards.
03More Advanced Capabilities & Platform Support Advanced
  • Bidding event callbacks: A new advanced capability supporting Bidding event callbacks — success / failure / impression callback APIs for greater flexibility.
  • Google Play inline installation: Adds support for Google Play inline installation, shortening the conversion path to lift eCPM and conversion rates.
  • Richer ad formats: A wider range of ad styles and types, covering interstitial, rewarded video, banner, native, and splash ads.
  • Whitelisted test devices: A whitelist test-device feature lets you test a single device, making verification more efficient and convenient.
  • Mediation platform upgrades: Third-party adapters updated for the latest versions of AdMob, GAM, MAX, Unity Ads, TopOn, and other mainstream mediation platforms.
